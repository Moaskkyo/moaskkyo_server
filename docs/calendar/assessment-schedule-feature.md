# 캘린더 수행평가 일정 조회 — 기능명세서

## 1. 기능설명

- 캘린더에서 내 반이 대상인 수행평가 일정을 볼 수 있다.
- 캘린더의 학사일정, 수행평가, 생일은 각각 다른 API로 조회한다.

## 2. 입출력

### 입력

- 조회 시작일, 조회 종료일 (캘린더 화면에 보이는 범위, 이전·다음 달 칸 포함)

### 출력

- 수행평가 표시 설정 여부
- 수행평가 목록: 과목 이름, 제목, 시작일, 종료일

## 3. 요구사항 / 제약조건

선생님 관련은 자세한건 admin에서 다루세요

- 로그인한 학생의 학교·학년·반이 대상인 수행평가만 조회한다.
- 현재 학년도의 수행평가만 조회한다. 학년도는 3월 1일에 바뀐다. (예: 2027-02-28까지는 2026학년도)
- 지난 학년도의 수행평가는 조회되지 않는다.
- 수행평가는 시작일~종료일로 내려주고, 하루 일정이면 시작일과 종료일이 같다.
- 조회 범위와 하루라도 겹치면 포함한다.
- 수행평가 표시가 on일 때만 조회한다. (기본값 on)
- 한 수행평가가 여러 반 대상이어도 학생에게는 하나로 보인다.
- 조회 범위는 최대 42일(6주)이다.

## 4. 흐름

- 캘린더 페이지 → 수행평가 조회(화면 범위)
- 이전 달 / 다음 달 이동 → 재조회

## 5. 비고

- 선생님 조회는 아직 구현되지 않았다. (선생님 계정·로그인이 생기면 admin 작업에서 연결)
- 학년이 바뀔 때 학생의 학년·반을 갱신하는 기능은 별도 작업이다. 갱신 전까지는 새 학년도 수행평가가 보이지 않는다.
- 날짜가 실시일인지 제출 마감일인지는 구분하지 않는다.
