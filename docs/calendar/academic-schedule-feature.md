# 캘린더 학사일정 조회 — 기능명세서

## 1. 기능설명

- 캘린더에서 공휴일, NEIS 학사일정, 선생님이 등록한 학사일정을 함께 볼 수 있다.

## 2. 입출력

### 입력

- 조회 시작일, 조회 종료일 (캘린더 화면에 보이는 범위, 이전·다음 달 칸 포함)

### 출력

- 학사일정 표시 설정 여부
- 일정 목록: 이름, 시작일, 종료일, 종류(공휴일 / NEIS / 등록)

## 3. 요구사항 / 제약조건

선생님 관련은 자세한건 admin에서 다루세요

- 로그인한 사용자의 학교 기준으로 조회한다.
- 공휴일과 NEIS 학사일정은 서버가 외부 API를 호출해 가져온다.
- 공휴일은 on/off 없이 항상 표시한다.
- NEIS·등록 학사일정은 학사일정이 on일 때만 조회한다. (기본값 on)
- 선생님은 캘린더 설정이 없으므로 항상 on으로 조회한다.
- 여러 날에 걸친 일정은 하나의 일정(시작일~종료일)으로 내려주고, 조회 범위와 하루라도 겹치면 포함한다.
- NEIS에서 날짜별로 나뉘어 오는 같은 이름의 연속 일정은 하나로 묶는다.
- 공휴일과 NEIS 일정이 같은 날짜·같은 이름이면 공휴일만 표시한다.
- 캘린더에 필요 없는 NEIS 항목(예: 토요휴업일)은 제외한다.
- 학년 구분 없이 전교생에게 동일하게 표시한다.
- 너무 긴 제목은 화면에서 '내용…'으로 생략한다.
- 조회 범위는 최대 42일(6주)이다.

## 4. 흐름

- 캘린더 페이지 → 학사일정 조회(화면 범위)
- 이전 달 / 다음 달 이동 → 재조회

## 5. 비고

- 선생님 조회는 아직 구현되지 않았다. (선생님 계정·로그인이 생기면 admin 작업에서 연결)
- 학생의 캘린더 설정을 회원가입 때 자동으로 만드는 기능은 별도 작업이다.
