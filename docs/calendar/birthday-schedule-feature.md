# 캘린더 생일 조회 — 기능명세서

## 1. 기능설명

- 생일 표시 여부 on인 같은 학교내의 학생들의 생일 정보를 캘린더에서 볼 수 있다.

## 2. 입출력

### 입력

- 조회 시작일, 조회 종료일 (캘린더 화면에 보이는 범위)

### 출력

- 생일 표시 설정 여부
- 생일 목록: 이름, 학년, 반, 번호, 날짜
    - 날짜에 따른 생일자의 이름과 학번 (학년·반·번호로 백엔드 응답)

## 3. 요구사항 / 제약조건

- 로그인한 학생과 같은 학교의 전 학년 학생을 대상으로 한다.
- 생일 공개 여부가 on인 학생만 조회된다.
- 캘린더 칸에는 이름 3자까지만 표시하고 나머지(4자 이상 이름의 뒷부분, 학번)는 생략한다. (ex. 김김김…)
- 태어난 연도는 내려주지 않고, 조회 범위에 해당하는 연도의 날짜로 내려준다.
- 2월 29일생은 윤년이 아닌 해에 2월 28일로 표시한다.
- 생일 표시가 on일 때만 조회한다. (기본값 on)
- 생일에는 세부 내용(메모)을 달 수 없다.
- 조회 범위는 최대 42일(6주)이다.
- 선생님은 조회하지 않는다.

## 4. 흐름

- 캘린더 페이지 → 생일 조회(화면 범위)
- 이전 달 / 다음 달 이동 → 재조회
