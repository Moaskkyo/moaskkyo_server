# 캘린더 조회 on/off 설정 변경 — 기능명세서

## 1. 기능설명

- 캘린더에 학사일정, 수행평가, 생일을 각각 표시할지 켜고 끌 수 있다.

## 2. 입출력

### 입력

- 바꿀 항목과 값 (학사일정 / 수행평가 / 생일 표시 여부)

### 출력

- 변경 후 전체 설정 (학사일정, 수행평가, 생일 표시 여부)

## 3. 요구사항 / 제약조건

- 대상 테이블: `calendar_setting` (학생 1명당 1개, 회원가입 시 생성, 기본값 모두 on)
- 부분 수정: 바꿀 항목만 보낸다. 보내지 않은 항목은 기존 값을 유지한다.
- 절대값 전달: "반전"이 아니라 바꿀 값(`true`/`false`)을 그대로 보낸다. 같은 요청이 두 번 가도 결과가 같다.
- 저장: DB에 저장되어 로그아웃하거나 기기를 바꿔도 유지된다.
- 선생님: 캘린더 설정이 없으므로 호출할 수 없다.

### 설정별 동작

| 필드 | 컬럼 | off일 때 |
| --- | --- | --- |
| showAcademic | show_academic | 학사일정 조회가 NEIS·등록 학사일정을 빼고 공휴일만 반환 (`enabled: false`) |
| showAssessment | show_assessment | 수행평가 조회가 빈 배열 반환 (`enabled: false`) |
| showBirthday | show_birthday | 생일 조회가 빈 배열 반환 (`enabled: false`) |

- 공휴일은 on/off 대상이 아니라 항상 표시된다.
- `showBirthday`는 내 캘린더에 생일을 띄울지에 대한 설정이다. 내 생일을 남에게 보여줄지(`birthday_public`)와는 별개다.

## 4. 흐름

- 캘린더 설정 화면 → 항목 on/off → 설정 변경 → 응답으로 받은 전체 설정을 화면에 반영

## 5. 비고

- 회원가입 시 `calendar_setting`을 만드는 기능은 별도 작업이다. 설정이 없는 학생은 404를 받는다.
- 현재 설정을 조회만 하는 API는 없다. 각 조회 API의 `enabled`와 이 API의 응답으로 값을 알 수 있다.
